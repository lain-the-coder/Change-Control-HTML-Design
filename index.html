Change Control Module — UI Prototypes

Interactive HTML prototypes for a workflow-driven Change Control system, covering every state of the six-state approval lifecycle from the perspective of each user role.

Static UI prototype — no backend. Navigation works between screens, but data does not persist and forms are illustrative. This is one part of a full design package: see the BRD, database design, and security matrix in the repository.
